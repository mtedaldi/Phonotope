# 0005 Project name: Phonotope

Status: accepted (2026-11-06)

## Context
The name should be generic enough for later extensions, descriptive, and
memorable. "Ambiator" was considered and rejected because a company of the
same name exists (a cooling-technology startup). "Phontastic" was considered
but is too playful as a main name.

## Decision
Name: **Phonotope**, a habitat made of sound. Playful variants appear in the
README only.

## Consequences
The term is an established concept (philosophy, music). GitHub name
availability and any trademark questions should be checked by the maintainer.
